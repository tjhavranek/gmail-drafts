Privacy policy

"gmail drafts" is a personal tool used only by its owner, Tomas Havranek, with his own Gmail account. It has no other users.

What data the tool accesses

With the owner's permission, the tool uses the Gmail API to create draft emails (scope gmail.compose) and to read messages and attachments in the owner's mailbox (scope gmail.readonly).

How the data is used and stored

The data is used only to help the owner prepare his own emails. It is processed on the owner's computer and with software tools he chooses to use for his own email, such as AI assistants. Access tokens are stored locally on the owner's computer.

Sharing

No data is sold, used for advertising, or shared with third parties for their own purposes. The use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
