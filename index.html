gmail drafts

"gmail drafts" is a small personal tool used by Tomas Havranek to prepare email drafts in his own Gmail account. It runs on his own computer and uses the Gmail API to create drafts and to read messages he has received, so that he can review and send replies himself. It does not send email.

The tool is not offered to anyone else and has a single user: its owner.
